# Portfólio — Ezequiel Lobo

Portfólio profissional estático desenvolvido com Next.js e publicado no Vercel.
O conteúdo prioriza leitura rápida por recrutadores e apresenta projetos por
problema, contribuição e evidências técnicas.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Executar localmente

```powershell
npm.cmd install
npm.cmd run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Verificações

```powershell
npm.cmd run lint
npm.cmd run build
```

## Atualizar conteúdo

As informações profissionais, competências e projetos estão centralizadas em
`content/portfolio.ts`. Imagens ficam em `public/profile` e `public/projects`.

## Publicação

Conecte este repositório ao Vercel mantendo as configurações padrão para
Next.js. Não há banco de dados, API externa ou variáveis de ambiente
obrigatórias.
